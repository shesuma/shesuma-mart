# D1 ER Diagram Notes

Entities required by the capstone guide:
Users, Products, Orders, Order Items, Cart Items, Reviews.

Relationships:
- User (seller) 1-to-many Products
- User (buyer) 1-to-many Orders
- Order 1-to-many Order Items
- Product 1-to-many Order Items
- User (buyer) 1-to-many Cart Items
- Product 1-to-many Cart Items
- User (buyer) 1-to-many Reviews
- Product 1-to-many Reviews
